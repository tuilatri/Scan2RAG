# v0.5.0 — Full Layer A Extraction & Review Workflow

Release date: 2026-11-28 · Tag `v0.5.0`

## What changed

- `scripts/build_canonical_facts.py` now scans **all 111 medical tables** across the 5 circulars, renders 200 DPI evidence images, and parses score rows: **1.163 facts + 3 guidance rules**. `88/111` tables contain parseable score rows; the rest are recorded as seen-but-empty.
- `scripts/review_canonical_fact.py` — human review CLI. An `agent` reviewer can never approve; approval requires `--evidence-checked`. Decisions are stored in `data/canonical/review_decisions.json` (gitignored).
- `scripts/audit_canonical_facts.py` now rejects any `authoritative` fact without a valid human decision, in addition to requiring a real evidence image.
- All generated entries remain `needs_human:true` / `authoritative:false` until a human signs off. **Nothing here is yet a decision source for the chatbot.**
- Project version bumped to `0.5.0` in backend `/health`, navbar badge, `package.json` and lockfile.

## Honest scope

This is the data foundation (Layer A2), not the deterministic decision engine (Layer C2). Graph and chat behavior are unchanged from v0.4.1. Full human sign-off of 1.163 facts is still outstanding.
