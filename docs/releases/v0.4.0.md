# v0.4.0 — Milestone 4: Evaluation & Grounding Guardrails

Release date: 2026-11-28 · Tag `v0.4.0`

## Highlights

- **Bộ 50 câu nghiệm thu** (`scripts/acceptance_questions.json`, `scripts/acceptance_run.py`) đo 4 trục: local model, cloud model, Qdrant retrieval, LangGraph compare. Có `--ids` để chạy lại từng câu; báo cáo JSON trong `data/exports/` (gitignore).
- **Chatbot là luồng chính**: giao diện so sánh đã gỡ khỏi tab; endpoint `POST /api/v1/query/compare` vẫn có cho backend/LangGraph.
- **Citation tin cậy hơn**: bảng điểm được ưu tiên trong rerank; câu hỏi vị trí bảng lấy đúng trang đầu của đúng văn bản; retention metadata `superseded_by`/`effective_date` đưa vào prompt chat.
- **Scope guard deterministic**: câu ngoài phạm vi (thời tiết, giá cả, vé máy bay, IQ, thơ ca) bị từ chối trước khi gọi LLM (~5–17 ms), không làm tốn token cloud.
- **Hạ tầng**: Qdrant server Docker với `check_qdrant.py` + hướng dẫn vòng đời trong `HOW_TO_RUN.md`.
